# Default cluster-scoped Kind list for the clusterScopedDelegation=parent
# carve-out: documents of these Kinds are moved out of the env deploy
# image's /kd/manifests into /kd/cluster-scoped-on-behalf (and the
# matching contents-zip folder) so the run-platform parent applies them
# with cluster credentials on the env's behalf.
#
# One Kind per non-blank, non-comment line. Files are single-document by
# project rule, so classification is per file.
#
# Files under src/data/ live in a sub dir per data set and are named
# <name>-<version>.txt. Each file is IMMUTABLE once published: content
# never changes - fixes or additions land as a new version (kept forever)
# and bad versions are removed outright, never edited. Builds pin a
# specific file, so a given version always means the same bytes.
#
# Users select a file by name with the clusterScopedKindsFile setting
# (MANIFESTS_CLUSTER_SCOPED_KINDS_FILE); the file is resolved in this
# fixed directory, so extensions can ship additional lists here. The
# selected file REPLACES this list entirely (no merge).

Namespace
